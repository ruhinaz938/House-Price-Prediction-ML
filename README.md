# 🏠 California House Price Prediction (Machine Learning)

An end-to-end Machine Learning regression project that predicts housing prices in California based on features like median income, house age, average rooms, and location.

## 🛠️ Tech Stack
* **Language:** Python
* **Data Manipulation:** NumPy, Pandas
* **Machine Learning:** Scikit-Learn (`RandomForestRegressor`)
* **Data Visualization:** Matplotlib

## 📊 Workflow
1. **Data Loading:** Loaded the California Housing dataset using `sklearn.datasets`.
2. **Data Splitting:** Split the dataset into 80% training and 20% testing sets.
3. **Model Training:** Trained a Random Forest Regressor model (`n_estimators=50`).
4. **Evaluation:** Evaluated model performance using Mean Absolute Error (MAE) and visualized Actual vs. Predicted prices using a scatter plot.
